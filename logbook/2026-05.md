**Method:** Inspected git state and pending decision files, promoted approved decisions into `decisions/human/`, ran `pnpm check`, searched local OpenClaw cron/config/log references for `NO_REPLY`, checked OpenClaw/ADB listeners, and ran `pnpm local:usb:start`.

## 2026-05-04 — Physical inbound receiver diagnosis (PER-158)

**Objective:** Determine why a real SMS into the Android gateway phone can arrive on the handset but not produce an OpenClaw reply.

**Method:** Verified the plugin routes and ADB tunnels, inspected Android package permissions/appops, checked dynamic broadcast receiver registration, sent a real Twilio SMS to the Android gateway SIM, watched Android broadcast/logcat output, and checked SMS Gateway/OpenClaw logs.

**Observations:** The SMS Gateway app is installed, enabled, foreground-service alive, and has `READ_SMS`, `RECEIVE_SMS`, and `SEND_SMS` appops allowed. Android broadcast state shows SMS Gateway registered for WAP push and sent/delivered callbacks, but not for `android.provider.Telephony.SMS_RECEIVED`. The physical Twilio SMS reached Android and was delivered to `com.android.mms`, with no corresponding `me.capcom.smsgateway` receiver or webhook log.

**Interpretation:** The current main failure is on the Android live inbound receiver path, not OpenClaw routing or outbound SMS. The attached Android 6 handset is in the same failure class already covered by the controlled Local Server inbox-export recovery decision.

**Resolution:** Added a physical Twilio probe mode to `pnpm tester:twilio` so agents can send a real carrier SMS into the Android gateway SIM and optionally trigger a bounded inbox export without asking the human to text by hand. Enabled live inbox-export recovery in `~/.openclaw/openclaw.json` with `catchUpOnStart=false`, `pollIntervalMs=15000`, and `safetyLagMs=5000`. After restarting OpenClaw and recreating ADB tunnels, `pnpm tester:twilio --physical --wait "Reply with exactly PHYSICAL_OK"` passed and a confirmation SMS was accepted by Android Gateway.

**Links:** PER-158 · `pnpm tester:twilio --physical --wait` · `pnpm tester:twilio --physical --trigger-export --wait`
