## 2026-04-21 — Android Local Server inbound recovery (PER-158)

**Objective:** Diagnose why inbound SMS stopped producing OpenClaw replies after the Android phone was powered off, reconnected, and restarted.

**Method:** Verified `pnpm local:usb:start`, Android Gateway health, adb forward/reverse, OpenClaw gateway status, SMS Gateway logs, Android storage state, Android lock-screen SMS notifications, and Local Server inbox export behavior.

**Observations:** The USB bridge and outbound SMS path were healthy. Android reported low storage (`mLowMemFlag=true`) but was not full. The phone received SMS in the system inbox, while SMS Gateway logs showed `Can't register receiver` and no live `ReceiverService::process` entries for new inbound SMS. Calling `/messages/inbox/export` caused SMS Gateway to process stored inbox messages and emit normal webhooks.

**Interpretation:** Low storage is a reliability risk on the handset, but the direct failure was SMS Gateway's live receiver not registering after reboot/background start. Local Server inbox export is a viable fallback for this device.

**Next:** Keep automatic inbox export polling enabled with startup catch-up disabled to avoid replaying old messages after gateway restarts. Clean phone storage separately if the handset remains in service.
